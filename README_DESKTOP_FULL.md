## 🔧 高级配置

### 调整窗口位置

编辑 `config/avatar_config.json`:

```json
{
  "window": {
    "width": 500,
    "height": 700,
    "x": -600,    // 负数=从右边计算（右下角）
    "y": -100     // 负数=从底部计算
  }
}
```

**常用位置预设：**
- 右下角：`"x": -600, "y": -100`
- 左下角：`"x": 100, "y": -100`
- 右上角：`"x": -600, "y": 100`
- 左上角：`"x": 100, "y": 100`

### 更换图片

1. 准备 PNG 图片（建议带透明通道）
2. 放入 `avatar/` 文件夹
3. 修改配置文件中的图片名

**图片要求：**
- 格式：PNG（支持透明背景）
- 尺寸：建议 500x700 像素
- 命名：英文小写，如 `happy.png`

### 调整语速

在代码中修改 `TTSSpeaker(rate=160)`：
- 慢速：`rate=120`
- 正常：`rate=150-160`
- 快速：`rate=200`

## ⚠️ 常见问题

### Q1: 语音识别不工作？
**A:** 检查以下几点：
1. 麦克风权限是否开启（Windows 设置 → 隐私 → 麦克风）
2. 是否有网络连接（Google API 需要联网）
3. 尝试说清楚普通话

### Q2: TTS 没有声音？
**A:** 
1. 检查系统音量
2. 确认默认播放设备正确
3. Windows 可能需要安装中文语音包

### Q3: 窗口不透明？
**A:** 
1. 确保安装了 PyQt5
2. 检查显卡驱动是否最新
3. 重启程序

### Q4: 点击不到后面的窗口？
**A:** 
1. 确认代码中有 `Qt.WA_TransparentForMouseEvents`
2. 某些全屏游戏可能不兼容
3. 尝试调整窗口位置
