## 🚀 快速开始

### 第一步：安装依赖

```bash
cd /workspace
pip install PyQt5 websockets
```

### 第二步：准备图片（差分图模式）

将您的立绘图片放入 `avatar/` 目录，命名如下：

```
avatar/
├── normal.png      # 普通表情
├── happy.png       # 开心
├── angry.png       # 生气
├── sad.png         # 伤心
├── surprised.png   # 惊讶
└── shy.png         # 害羞
```

> 💡 **提示**: 图片要求
> - 格式：PNG（支持透明背景）
> - 尺寸：建议 500x700 或更高
> - 背景：透明或纯色

### 第三步：启动桌面宠物

```bash
# 差分图模式（推荐新手）
python desktop_pet.py --mode avatar

# Live2D 模式（需要模型文件）
python desktop_pet.py --mode live2d
```

### 第四步：启动主程序（新命令行）

```bash
streamlit run webui.py
```

## 🎯 两种模式对比

### 模式 A: 差分图 ⭐⭐⭐⭐⭐ (推荐)

**优点**:
- ✅ 资源占用极低 (<100MB 内存)
- ✅ 设置简单（只需 PNG 图片）
- ✅ 切换流畅无延迟
- ✅ 适合您的配置

**效果**:
```
[桌面] ┌─────────────┐
       │   爱丽丝    │ ← 透明悬浮窗
       │   立绘     │ ← 根据对话切换表情
       └─────────────┘
```

### 模式 B: Live2D ⭐⭐⭐⭐

**优点**:
- ✅ 动态呼吸/眨眼
- ✅ 更生动的表现
- ✅ 专业 VTuber 效果

**缺点**:
- ⚠️ 需要下载/制作.model3 模型
- ⚠️ 需要集成 Cubism SDK
- ⚠️ 占用更多资源 (~300MB)

## 🔧 配置文件说明

### avatar_config.json

```json
{
  "window": {
    "width": 500,      // 窗口宽度
    "height": 700,     // 窗口高度
    "x": 100,          // X 轴位置
    "y": 100           // Y 轴位置
  },
  "images": {
    "normal": "normal.png",  // 表情映射
    "happy": "happy.png"
  }
}
```

## ❓ 常见问题

### Q1: 窗口不显示？
**A**: 检查是否安装了 PyQt5
```bash
pip install PyQt5
```

### Q2: 图片加载失败？
**A**: 确认图片路径和文件名正确
```bash
ls avatar/
```

### Q3: 如何调整窗口位置？
**A**: 修改 `config/avatar_config.json` 中的 x/y 值

### Q4: 鼠标点不到桌面图标？
**A**: 这是正常的（鼠标穿透），窗口不会阻挡点击

### Q5: 如何退出程序？
**A**: 按 Ctrl+C 或在任务管理器中结束进程
